TRANSPARENCY & PROVENANCE

Data sources & limitations

Each feed has a defined purpose and limitations. Missing data is never replaced with fabricated current values.

Integrated external sources

  • Open-Meteo Forecast API — current modelled temperature, humidity, precipitation, rain and wind at configured coordinates. Documentation
  • Copernicus Data Space STAC API — satellite product catalogue metadata for Sentinel-1 GRD and Sentinel-2 L2A over Nepal's bounding region. Catalogue API
  • Nepal Department of Hydrology and Meteorology (DHM) — official forecasts and warnings. Official flood forecasting portal · DHM website
  • ICIMOD — Himalayan research and regional hazard resources. ICIMOD

DHM information is linked for authoritative reference; this application does not claim an automated DHM feed or relay official warnings.

Interpretation and limitations

  • Open-Meteo values are modelled weather context, not direct river gauge measurements or a validated flood forecast.
  • Satellite catalogue entries are product metadata only. Flood mapping requires downloading and processing imagery, validation, and appropriate geospatial methods.
  • Cloud cover, satellite revisit time, product latency and terrain can limit satellite usefulness.
  • Staff risk assessments are workflow records, not scientifically validated forecasts.
  • Application alerts are internal records. The application does not send emergency notifications or issue official warnings.
  • When a source is unavailable, the application displays an unavailable state rather than inventing values.
  • Monitoring site coordinates are initial configured points and should be checked against authoritative geographic datasets before operational use.

Cloud operations

The application supports a PostgreSQL connection through DATABASE_URL. Optional AWS CloudWatch application logging can be enabled with CLOUDWATCH_LOG_GROUP and an IAM role with permission to write logs. Optional S3 snapshot archival can be enabled with S3_BUCKET_NAME and an IAM role with permission to write to the designated bucket.

AWS resources must be provisioned and IAM permissions configured in your own AWS account. This code package does not claim that an AWS deployment has already been created.
